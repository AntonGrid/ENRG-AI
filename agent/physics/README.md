# `agent/physics` — парк как одна среда

Слой L3 оракула ENRG-AI. Каждый производитель — осциллятор, состояние которого
есть **частота**; то, что у двух производителей общего, записывается в **связь**
между ними. Отсюда четыре чтения на производителя: `silence`, `resonance`,
`phase`, `memory` → `score ∈ [0, 1]`.

Математика — порт `entrain/julia/kuramoto/basic.jl`, сверенный с Julia **до
последнего бита** (`tests/fixtures/entrain_reference.json`). Граница «что этот
слой делает, а чего не делает никогда» — `entrain/docs/ENTRAIN-BOUNDARY.md`;
история интеграции — `docs/PHYSICS_INTEGRATION_SUCCESS.md`.

## Что здесь лежит

| `plots.py` | `plot_depin_dynamics` — счётчик, `R` и рельеф против `e^(−εt)` одной картинкой |

| `organism.py` | тело: три фазы (слепая → обучение → осознание), отчёт и картинка |
| `curiosity.py` | аппетит: во сколько обойдётся внимание к потоку и что спросить первым |
| `economy_sim.py` | рынок: что стоит вердикт, сколько стоит ждать, и что такое смерть |
| `worker.py` | работник: брать ли контракт, отказ с причиной, эпизодическая память |
| `__main__.py` | CLI: читает парк и пишет `coherence.json` |

## Одиннадцать функций

Все — из `entrain/julia/kuramoto/basic.jl`; номера строк указаны, чтобы сверка
была построчной.

| функция | что читает | в книге |
|---|---|---|
| `overlap(delta, band)` | `S(Δ) = 1 / (1 + (Δ/Π)²)` — насколько совпали две частоты | `basic.jl:243` |
| `coherence(theta)` | `R = \|mean e^{iθ}\|` — согласованность (порядок) | `basic.jl:378` |
| `partial_coherence(theta, mode)` | тот же `R`, но по одному голосу аккорда | `basic.jl:381` |
| `resonance(omega)` | `max ω − min ω` — ширина всей среды | `basic.jl:408` |
| `spread(omega, index)` | ширина аккорда одного вибратора | `basic.jl:415` |
| `chord(omega, theta, t)` | `mean cos(ωt + θ)` одного аккорда в момент `t` | `basic.jl:393` |
| `wave(omega, theta, t)` | `mean cos(ωt + θ)` по всей среде | `basic.jl:400` |
| `unison(omega, omega0)` | `1 − spread/spread₀` — насколько аккорд сжался | `basic.jl:423` |
| `coincidence(theta, index)` | `mean cos(θp − θq)` внутри аккорда | `basic.jl:436` |
| `memory_goal(link, K, acc, weight, current, reference)` | цель записанной связи `(link + N₀·cos)/K` | `basic.jl:312` |
| `memory_step(coupling, target, eps, dt)` | один шаг записи `W += dt·ε·(target − W)` | `basic.jl:358` |
| `step_state(...)` | полный шаг закона: `ω`, `θ`, `W` вместе | `step!` |

Чтение парка (`park.py`) использует `overlap`, `coherence` и `memory_goal`;
остальные перенесены целиком, потому что порт либо полный, или его нет:
частичный порт нельзя сверить с эталоном построчно.

## Быстрый старт (CLI)

Из каталога `ENRG-AI` (нужен интерпретатор, где установлены `numpy` и сам
пакет — например `.venv/bin/python`):

```bash
# парк с четырьмя объявленными изменениями → coherence.json
python -m agent.physics --scenario mixed --output coherence.json

# тот же парк без изменений: чтение должно молчать
python -m agent.physics --scenario clean

# живой оракул; если он недоступен или в нём один производитель —
# тихий откат на офлайн-парк, source="offline-fallback" + warning
python -m agent.physics --source online --output coherence.json

# подписать Ed25519 (ключ — base64 seed в переменной окружения)
AXIS_AI_SIGNING_KEY="$(cat key.b64)" python -m agent.physics --sign \
```

### Флаги

| флаг | по умолчанию | смысл |
|---|---|---|
| `--source` | `offline` | `offline` — синтетический парк, `online` — пруфы оракула |
| `--scenario` | `mixed` | `mixed` — четыре изменения, `clean` — исправный парк |
| `--seed` | `7` | сид синтетики; на 7/11/23/42 вердикт один и тот же |
| `--bucket-minutes` | `60` | ширина корзины; 60 при суточном обороте = 24 отсчёта |
| `--window` | `0` | прочитать только последние N корзин (0 — всю историю) |
| `--baseline-hours` | `96` | сколько часов «нормы» парк выучивает до чтения |
| `--band` | `0.05` | Π: полоса, в которой частоты считаются совпавшими (рад/ч) |
| `--memory-hours` | `12.5` | время жизни записанной связи (`1/ε`) |
| `--threshold` | `0.5` | порог score, выше которого производитель помечен |
| `--limit` | `1000` | сколько пруфов забрать у оракула (`--source online`) |
| `--output` | — | путь для JSON; без него только печать |
| `--sign` | выкл. | подписать конверт `AXIS_AI_SIGNING_KEY` |

## Что внутри `coherence.json`

Это обычный `SignalBundle` оракула — тот же конверт, что подписывает
`agent.signals`; новый здесь только `kind`. Без `--sign` — три ключа,
с `--sign` — конверт `{message, signature, public_key}`.

```json

  "meta": {
    "source": "offline",
    "physics": {
      "engine": "entrain",
      "source_file": "entrain/julia/kuramoto/basic.jl",
      "ported": ["overlap", "coherence", "partial_coherence", "resonance",
                 "spread", "chord", "wave", "coincidence", "memory_goal",
                 "memory_step", "step_state"],
      "components": ["silence", "resonance", "phase", "memory"],
      "config": {"bucket_minutes": 60, "band_rad_per_hour": 0.05,
                 "memory_hours": 12.5, "baseline_hours": 96.0,
                 "threshold": 0.5, "...": "..."}
    },
    "park": {"coherence_mean": 0.9156, "coherence_min": 0.8523,
             "silent_fraction": 0.0347, "producers": 8, "window_buckets": 72},
    "devices": [
      {
        "device_id": "dev-00",
        "score": 0.249,
        "is_anomaly": false,

                     "memory_divergence": 0.099619, "resonance_s": 0.999999,
                     "detune_rad_per_hour": 3.7e-05,
                     "period_hours": 23.976646, "coherence": 0.915588},
        "anomaly_since": null
      }
    ],
    "warnings": []
  },
  "signals": [
    {
      "kind": "coherence",
      "domain": "pilot",
      "ts": "2026-10-20T11:00+00:00",
      "source": "offline",
      "value": 1.0,
      "unit": "score",
      "meta": {"device_id": "dev-02", "is_anomaly": true,
               "reasons": ["silence"], "components": {"...": "..."},
               "readings": {"...": "..."},
               "anomaly_since": "2026-10-18T23:00+00:00"}
    }
  ]
}
```

Два правила, которые стоит знать заранее:

- `signals` содержит **только помеченных** производителей (провод молчит), но
  `meta.devices` содержит **всех** — чтение никого не выбрасывает, оно просто
  не всех произносит вслух;
- `readings` — сырые величины, из которых сложился score: `phase_drift_rad`
  (сдвиг суточного пика в радианах), `period_hours` (собственный период
  производителя), `resonance_s` (`S(Δω)` — насколько его частота совпала с
  парком), `memory_divergence` (насколько разошлась записанная связь).

## Проверка подписи

```python
import json
from agent.signals import verify_bundle_signature

payload = json.load(open("coherence.json"))          # созданный с --sign
assert verify_bundle_signature(payload["public_key"], payload)   # True

payload["message"]["meta"]["devices"][0]["score"] = 0.0   # любая подмена
assert not verify_bundle_signature(payload["public_key"], payload)  # False
```

Формат не новый — проверка та же, что у остальных сигналов оракула
(`agent.signals.verify_bundle_signature`, канонический JSON из
`agent.fed.protocol`).

## Использование из Python

```python
from agent.forecast.energy import fetch_oracle_proofs
from agent.physics import (
    ParkConfig, coherence_bundle, observe_park, park_matrix, park_signals,
)

proofs = fetch_oracle_proofs(limit=1000)              # пруфы оракула (ADR-0010)
matrix = park_matrix(proofs, bucket_minutes=60)       # производители × часы
observation = observe_park(
    matrix.energy, matrix.device_ids, matrix.starts, ParkConfig(bucket_minutes=60)
)

observation.park_reading()   # {"coherence_mean": ..., "silent_fraction": ...}
observation.rows()           # все производители: score, readings, reasons
park_signals(observation)    # [CoherenceSignal, ...] — на каждого
bundle = coherence_bundle(observation, source="oracle")   # SignalBundle
```

Дальше сигнал идёт в существующий opt-in гейт политики (Axis-core), без нового
флага и без нового кода причины:

```python
from axis_core.policy import engine, models

signal = next(s for s in park_signals(observation) if s.is_anomaly)
engine.PolicyEngine.evaluate_ai_anomaly(
    policy=models.PolicyRegistry(), signal=signal
).allowed                                                   # True — флаг выключен
engine.PolicyEngine.evaluate_ai_anomaly(
    policy=models.PolicyRegistry(enforce_ai_anomaly=True), signal=signal
).reason                                                   # "ai_anomaly_flagged"
```

`coherence_bundle` возвращает обычный `SignalBundle`: `sign_bundle` и
`verify_bundle_signature` работают с ним без правок.

## Что слой не делает

- **Не видит уровень.** Множитель `×k` фазу не двигает: изменение уровня —
  работа правил (Axis-core), не физики.
- **Не заменяет подпись.** Согласованность не доказывает авторство; подпись не
  доказывает согласованность.
- **Ничего не разрешает.** Ни минта, ни начисления, ни расчёта ERS: только
  наблюдение для оператора (и opt-in гейт, если оператор его включил).
- **Не работает без истории и без соседей.** Нужны ≥ 2 производителя, один
  оборот (сутки) и базовая линия (`--baseline-hours`, по умолчанию 96 ч).
- **Это чтение отчётов, а не измерение физики.** Парк, который врёт
  согласованно, остаётся невидимым — свойство метода, записано в границе.

## Автопоэтический слой: сенсориум → гомеостаз → зеркало

Над парком лежит тело, которое растёт вокруг ядра и не меняет в нём ни строки.
Три стадии — три модуля, и одна команда:

```bash
python -m agent.physics.organism --output report.json --plot phases.png
python -m agent.physics.organism --offline --steps 120    # без сети вообще
```

**Сенсориум** (`sensorium.py`). Пять лент по умолчанию — рынок (`finance:BTC-USD`),
поле Земли (`physics:noaa-kp`), пятна (`physics:sunspots`), внимание
(`behavior:pageviews`) и работа (`behavior:commits`) — три домена, потому что
система, вскормленная одним типом шума, выучивает этот шум и называет его миром.
Плюс `listen_dataset`/`listen_file`, чтобы тело могло родиться без сети. Сны — четыре
вида, и последний неотличим: `phase_randomise` сохраняет и периодограмм, и
**точную** гистограмму мира; его не берёт ни одна локальная статистика, и это
измерено, а не заявлено.

**Гомеостаз** (`homeostasis.py`). λ (темп записи мира в модель класса), ε
(забывание — оно же старит реестр собственных излучений) и α (объявленный риск;
порог `τ = null_threshold(n, α)` берётся из ядра и никогда не выбирается вручную).
Поиск идёт тремя фазами: сетка → мутации (8% на параметр, лог-нормально, с
откатом) → Powell → тонкие мутации. Приём элитарный, поэтому «лучшая цель» —
монотонная кривая, а не обещание; масштаб мутации адаптируется по правилу 1/5
успеха. Цель — **макро**-среднее (по каждому потоку отдельно): общее усреднение
вознаграждает тело, которое помнит только последнее услышанное (измерено: поток,
услышанный последним, получал 1.0, а первый — 0.32 при общем 0.69).

**Зеркало** (`self_model.py`). Метрика — отношение правдоподобий двух диагональных
гауссианов над одними признаками:

```
R_int = sigmoid(ℓ_world − ℓ_self)
reality_score = (1 − r) · sigmoid(logit R_int + logit P(world))
```

где `r = e^{−εΔt}` — память о том, что ровно эти байты были излучён. Отношение, а не
расстояние: расстояние до среднего говорит «мир непредсказуем», что противоположно
смыслу слова «настоящее» (измерено: AUC 0.47 у версии на расстоянии против 0.92 у
отношения в том же эксперименте).

Жёсткое правило объявлено до запуска и проверяется тестом: *после интеграции средний
`reality_score` для реальных данных выше 0.7, а для собственных симуляций ниже 0.3*.
Прогон по умолчанию (5 лент, 3 домена, сид 11): **мир 0.79, свои 0.07, AUC 0.92**;
без реестра, только статистикой — 0.79 / 0.35, и это печатается рядом, а не
прячется.

Что слой **не** делает:

- **не трогает ядро**: `genome.verify` пересчитывает SHA-256 `theorem.py` и
  `detector.py`, и отпечаток уходит в каждый отчёт;
- **не выдаёт статистику за память**: собственный суррогат, у которого нет
  отпечатка в реестре, читается как мир — но и он берётся реестром, пока организм
  помнит, что его сделал; после `1/ε` шагов забывания он честно становится
  «миром» (кривая фантома в ноутбуке);
- **не претендует на сознание**: число, полученное отношением правдоподобий, — не
  переживание. Демонстрация: `notebooks/emergent_consciousness.ipynb`.

## Активный исследователь: любопытство как цена внимания

Зеркало отвечает на вопрос «это мир или это я?». Следующий вопрос другой: **какому
потоку стоит посмотреть ещё раз**, если смотреть на все сразу нельзя. Ответ —
`curiosity.py`: ожидаемый прирост информации, разложенный на четыре измеряемых
множителя, которые можно распечатать и оспорить по отдельности:

```
curiosity = R                                    реальность (вердикт зеркала)
          × 2V / (V + V_ref)                     движение в кадре, гейт, не сигнал
          × (1 − e^(−Λ / 0.25))                  структура: сколько поток объясняет себя
          × 1 / (1 + 0.5 · looks)                сколько раз уже спрашивали
```

Каждый множитель — гейт, а не добавка: поток, который не движется, стоит ровно ноль,
даже если он реален; поток, который движется, но не объясняет себя, тоже ноль, даже
если он движется сильнее всех. Порядок множителей — это порядок вопросов, на которые
тело уже умеет отвечать, и ни одного нового числа в модель не добавлено.

**Структура** считается не «на глаз»: признаки 24 окон (7 штук на окно, вместе с
реальностью окна) проверяются на самоподобие с лагом, а значимость — против **точного**
нуля `P(R² > r) = (1 − r)^((n−2)/2)`, с поправкой Бонферрони по лагам. Измерено на
чистом шуме (120 прогонов): при `α = 0.5` ожидалось бы 50% срабатываний, измерено
0/120 при любом α от 0.5 до 0.01 — тест консервативен, и это напечатано, а не
заявлено. Причина арифметическая: на лаге 21 из 24 окон остаётся три пары, и чтобы
хвост `(1−R²)^((3−2)/2)` упал ниже `0.5/21`, нужно `R² ≥ 0.9994`. Объявленный α —
граница, которую гейт обходит с запасом, ошибаясь только в сторону молчания; цена
этого — чувствительность, она измерена ниже. Тридцать три потока без повтора
(30 перестановок настоящего ряда, случайное блуждание, AR(1), замороженный датчик) —
0 срабатываний, максимум `R² = 0.000`.

**Что видно на сенсориуме.** Рядом с тремя честными лентами кладутся четыре
кандидата, ни один не помечен, у всех `origin = world`:

| поток | `curiosity` | `structure` | `reality` | `V` |
|---|---|---|---|---|
| `forger:block256` (блок 256 отсчётов, повторённый) | **0.815** | 20.72 nats | 0.815 | 0.300 |
| `forger:replay` (первая половина вместо второй) | **0.807** | 1.78 nats | 0.852 | 0.237 |
| `control:copy` (те же байты, **без** повтора) | 0.000 | 0.00 | 0.827 | 0.263 |
| `dead:sensor` (среднее вместо сигнала) | 0.000 | 0.00 | 0.000 | 0.000 |
| три честные ленты | 0.000 | 0.00 | 0.53 … 0.99 | — |

`control:copy` в таблице не для полноты: это те же самые байты, что у подделки, и
единственное их отличие — отсутствие повтора. Различается не метка, а арифметика.

Одно число заслуживает объяснения: у `forger:replay` `R² = 0.83`, а не 1.00. Копия
точная — одиннадцать пар окон из двенадцати совпадают бит в бит, — но окно

**Вопросы.** Когда `curiosity ≥ 0.35`, тело задаёт вопрос — и это не запрос «дай
ещё данных», а один из трёх ходов, которые у него уже есть: `context` (что было
вокруг самого неожиданного места), `next` (следующий пакет того же потока) и
`compare` (этот поток рядом с наименее интересным). Каждый вопрос стоит доли
любопытства (`LOOK_COST = 0.5`) и **не** добавляется в обследование: ответ — срез, а
не новый поток, и если бы он дописывался в матрицу окон, заданный вопрос менял бы ту
самую структуру, из-за которой был задан. На прогоне по умолчанию: шесть вопросов,
`0.815 → 0.546 → 0.410 → 0.326` и `0.807 → 0.540 → 0.407 → 0.325`, дальше

перейдён; счётчик (`MAX_PROBES`) — ремень, а не причина.

**Чего слой не видит** (измерено в ноутбуке, раздел 8):

- **периодичность сводки, а не payload.** Чистый синус с периодом 512 отсчётов
  возвращается на лаге 4 с `Λ = 6.85` (признаки инвариантны к смене знака, полпериода
  — честный ответ в этом кадре), но `reality = 0.000`: зеркало никогда не слышало
  сигнала без шума и говорит об этом. Структура без реальности не стоит ничего;
- тот же синус с `σ = 0.3` шума не считается повтором вовсе: сводки окна меняются
  меньше, чем шум, и после того как фаза потеряна, искать самоподобие не в чем;
- подделка блоком 128 отсчётов (ровно одно окно: два чередующихся окна предсказывают
  друг друга наклоном −1, поэтому лаг 1, а не 2) видна (`R² = 1.000`), но `V = 0.0035` —
  окна почти не отличаются друг от друга, и гейт движения отдаёт `0.007`.

Сказать это прямо важнее, чем спрятать: детектор отвечает на вопрос «это то же самое
окно ещё раз» — ровно на тот, который задаёт подделка, — и не отвечает ни на вопрос
«это мелодия», ни на вопрос «это подделка не длиннее окна».

## Экономический агент: вердикт, у которого есть цена

Тело научилось слушать, судить свою подделку и решать, куда смотреть. Не хватало
третьего: **стоит ли вообще браться**. `economy_sim.py` — рынок, на котором это
решается, и он состоит из трёх чисел: награда 50, штраф 30, аренда вычислений 10
каждые 4 итерации (2.5 за итерацию, независимо от того, нашлось ли работа).
Старт — 50 кредитов.

**Контракт.** Клиент приносит три потока и вопрос «один из них синтетический —
найди его». Вид подделки назван вслух, а како́й именно поток — нет: в объекте
`Contract` нет поля с ответом, рынок хранит его в закрытой таблице и открывает
только в `Settlement`, после оплаты вердикта. Агент не может прочитать ответ,
потому что в объекте, который ему дали, ответа нет, — это единственная честность,
которая выдерживает любопытного агента.

| вид | что подделано | тело решает? |
|---|---|---|
| `repeat` | блок настоящей записи (256 отсчётов), повторённый | да: разрыв структуры ≈ 20.7 нат |
| `replay` | вторая половина — копия первой (768 отсчётов, кратно шагу 64) | да, с меньшим запасом (R² = 0.83) |
| `surrogate` | фазовый суррогат: тот же спектр, случайные фазы | **нет**: разрыв ровно 0.00 нат |
| `noise` | белый шум с теми же средним и разбросом | **нет**, по той же причине |

Половина рынка телу не по силам, и это не дефект рынка, а его смысл: если все
контракты решаемы, агент, берущий всё подряд, неотличим от монетки.

**Почему штраф 30, а не 20.** При 50/20 и трёх потоках слепая догадка стоит
`(50 − 40)/3 = +3.33` за контракт: тогда «брать всё и угадывать» — оптимальная
политика, и отказ был бы не осторожностью, а ошибкой. При 50/30 та же догадка
даёт `−3.33`, а точка безубыточности становится `30/80 = 0.375` — арифметикой, а
не характером. Арифметика записана в докстроке модуля и закреплена тестом
(`test_anton_s_numbers_would_have_made_guessing_profitable`).

**Уверенность** (`curiosity.certainty`) — измеренная, а не заявленная:

```
margin        = structure(лучший) − structure(второй)        нат
significance  = 1 − p-tail победившего лага
stability     = доля из 5 возмущений данных (5% σ), где победитель тот же
uncertainty   = 1 − stability                                эпистемическая
resonance     = разброс internal_resonance зеркала по потоку
probability   = 1 − e^(−margin/0.25), но не меньше 1/3 при отсутствии доказательств
```

Возмущение — не бутстрап: бутстрап меняет *набор окон* и меряет ошибку выборки, а
здесь вопрос жёстче: изменится ли ответ, если эти же окна сдвинуть на пять
процентов их собственного разброса. Два измеренных случая: у настоящего повтора
`margin = 20.72`, `stability = 1.00`; у фазового суррогата `margin = 0.00`,
`suspect = None`, `probability = 1/3` — то есть «не знаю», записанное числом.

**Решение** (`worker.py`) — одна формула и три её следствия:

```
p_hat = w · P_evidence + (1 − w) · belief(memory)
взять ⟺ p_hat ≥ penalty/(reward + penalty) = 0.375
```

где `w = stability` (доказательство против памяти), а `belief` — **нижняя** граница
доли побед по этому виду работ: среднее минус одна стандартная ошибка. Среднее врёт
в обе стороны, но ошибка в свою пользу стоит штрафа, а против себя — работы, поэтому
решает пессимистичная сторона: одна удачная догадка не открывает безнадёжный вид
заново (`trust = 0.42 > 0.375`, `belief = 0.17 < 0.375`).

Третий случай — вид работ, которого тело не пробовало: доказательств нет, память на
уровне случая, `p = 1/3` и отказ навсегда. Чтобы тело не осталось слепым к четверти
рынка, объявлен **бюджет платных уроков**: не больше двух взятий на вид, только
пока баланс выдерживает штраф и только пока таблица UCB (`curiosity.UCB`, правило
UCB1) всё ещё считает вид перспективным. Этот бюджет и даёт на графике фазу
обучения — он тратится видимо, в журнале, а не прячется в сиде.

| правило | когда | что делает |
|---|---|---|
| доказательство | `p_hat ≥ 0.375` и ответ выдерживает возмущение | берёт: «p=1.00 ≥ 0.375: margin 20.72 нат» |
| инвестиция | доказательств нет, но вид не изучен и урок по карману | берёт: «lesson 1 of 2 on surrogate, table 2.04» |
| сохранение капитала | доказательств нет и штраф не по карману (или уроки кончились) | отказывается: «a lesson costs 30 against a balance of 20» |

**Измерено** (сид 11, 120 итераций): 65 взято, 62 верно (95%), 55 отказов, отказы
сохранили **1050 кредитов** штрафов, баланс 2760 из стартовых 50. `surrogate` и
`noise` взяты по два раза (уроки) и дальше отклоняются всегда; `replay` взят 19 раз
и выигран 18. Отдельно прожито ещё три жизни (100 и 75 итераций): все в плюсе, но
самая неудачная опускалась до 20 кредитов — риск настоящий.

**Где проходит граница с ядром.** Ни строки в `entrain`: рынок режет контракты из
записи, которую слышит сензориум, вердикт считает зеркало, решение — та же
арифметика, что и в `curiosity`. Экономика добавляет только цену и отказ.


## Цифровой предприниматель: капитал, ловушка и рубильник

Работник зарабатывал по одному контракту. Четвёртый слой задаёт следующий вопрос,
который возникает у тела с балансом: **что делать с деньгами между работами?** Ответ
— не «туда, где доходность выше» (в этом рынке самая высокая доходность у тех, кто
врёт), а **потолок**.

**`portfolio.py`** — три ведра и доли 60/30/10: стейкинг в надёжном протоколе,
активные баунти и MEV, экспериментальная ферма. Доли — не диверсификация ради
диверсификации, а ответ на вопрос «какой худший ущерб нанесёт одна ошибка»: при
таком делении протокол, ушедший в ноль, стоит **десятой части империи**. Белый список
адресов обязателен и **недостаточен**: он говорит, что кто-то проверил, *кто управляет
адресом*, и ничего — о том, является ли кривая записью. Оба мошенника этого рынка в
белом списке именно поэтому. Капитал на адрес вне списка не уходит никогда:
`NotWhitelisted` — это ошибка, а не отказ (отказ — решение, а это баг), и пустой
белый список не разрешает ничего.

**`risk_assessment.py`** — Statement #87, повёрнутый на кривую доходности. Три
измерения, у каждого своё слепое пятно:

| измерение | что видит | чего не видит |
|---|---|---|
| `A²`, `CV` (`sterility`) | запись без остатков — это формула | **облигация тоже стерильна** |
| `R²` (`reducibility` через позу тела) | запись, которая пересказывает себя | шумную ложь |
| `reality`, `resonance` (зеркало) | «я такого не слышало» | что именно не так |

Ни одно не может осудить в одиночку, и причина измерена, а не заявлена: у договорной
облигации `CV = 1e-4` и нет остатков — ровно подпись формульной ловушки, и никакая
статистика записи их не различит. Одно — обещание, которое держат; другое — обещание,
которое не держат; оба обещания. Поэтому вердикт требует согласия двух рук:

```
sterile | repeat | unreal   ->  запись не является записью
promised | inflated         ->  обещание не таково, каким его мог бы заплатить рынок
оба                         ->  SCAM_TRAP
только первая               ->  SYNTHETIC_COLLUSION   (отказ; цена отказа измерена)
только вторая               ->  SUSPECT               (отказ: «покажи запись»)
ни одна                     ->  HONEST                (деньги разрешены)
```

`promised` — обещание выше потолка, объявленного **на ведро** (`PLAUSIBLE_APY`:
35 % / 300 % / 400 %). 1000 % в стейкинге невозможно, 350 % в ферме — обычное дело, и
ведро — это то место, где империя уже сказала, сколько она готова потерять.
`inflated` — обещание выше записи на три стандартные ошибки: не «врёт», а «пока не
подтверждено», поэтому `SUSPECT`, а не приговор.

Измерено на объявленном рынке (сид 7, шаг 280 — последний спокойный пересмотр, все
семь протоколов ещё платят; прочерк в `R²` — структурной руке нужны четыре окна
записи, то есть 320 отсчётов, и до этого шага она не имеет права говорить «нет
повтора»):

| протокол | обещает | платит | `A²` | `CV` | `R²` | вердикт |
|---|---|---|---|---|---|---|
| StakingVault | 7 % | 4 % | 1.33 | 3.57 | — | `HONEST` |
| FixedBond | 20 % | 20 % | 0.29 | 0.0001 | — | `SYNTHETIC_COLLUSION` |
| BountyBoard | 177 % | 33 % | 62.6 | 4.46 | — | `SUSPECT` |
| MevRouter | 95 % | 94 % | 0.77 | 1.68 | — | `HONEST` |
| NicheFarm | 350 % | 365 % | 25.9 | 4.19 | — | `HONEST` |
| YieldMax | 1000 % | 1003 % | 0.85 | 0.0001 | — | `SCAM_TRAP` |

`BountyBoard` — не мошенник, а третья полоса: он обещает 177 % и за первые двести
восемьдесят шагов заплатил 33 %, что на три с лишним стандартные ошибки меньше
обещанного. Ответ — «покажи запись», `SUSPECT`, и на шаге 360, когда джекпоты

336 — за четырнадцать шагов до изъятия. **Разные ловушки ловятся разными руками в
разное время**, и журнал это показывает, а не сглаживает.

**Рубильник** — три независимых измерения и одно действие:

| рука | когда | что измерено |
|---|---|---|
| `drawdown` | капитал упал на 15 % **за цикл** (24 шага) | правило из брифа; ловит медленный крах |
| `volatility` | разброс рынка втрое выше своей истории | ловит смену режима, когда потерь ещё нет |
| `resonance` | средний `internal_resonance` держимых записей ниже порога | ловит запись, которая перестала быть записью |

Что измерено про сами руки: медленный крах (−2.4 % в шаг) срабатывает по просадке на
шаге 403 («equity fell 15.6 % over one cycle»), обвальный (−7.5 % в шаг) — по
волатильности на шаге 475. Рука резонанса в этом прогоне не сработала и не могла:
империя ни разу не держала запись с рухнувшим резонансом, потому что оценка отказывает
таким до покупки; она проверяется тестом, где это единственная рука, способная
сработать. Отдельная тонкость, найденная измерением: базовая волатильность не может
считаться по последним 90 шагам — она догоняет крах за шесть шагов, и отношение
`−7.5 %`-режима к собственному последствию равно 1.6, то есть «спокойный рынок».
Базой стала вся опубликованная история.

**Измерено** (720 шагов, сид 7, одно тело): капитал **100 → 149**, ни один шаг не
ниже старта, 28 пересмотров, на каждом отказано пяти протоколам из семи, обе ловушки
приговорены **до** изъятия, худшее падение от максимума — **15.9 %**. Те же потолки
