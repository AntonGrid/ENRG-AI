# Физика в ENRG-AI: что сделано, что измерено, чем это отличается

> **English abstract.** ENRG-AI now reads a park of producers as one medium: each
> producer is an oscillator whose state is a frequency, and what two producers
> have in common is written into the link between them (`agent/physics/`, 8
> modules, 64 tests). The maths is a bit-exact port of a Julia reference
> implementation — every function is checked against it to the last bit. On a
> declared 168-hour park of 8 producers the reading catches a day-long outage, a
> four-hour peak shift and a **two-hour timestamp lie** with **precision 1.00 and
> zero false alarms**, while the level (MAD) rules fire on every untouched
> producer (precision 0.50, four false alarms). It is blind to a pure level
> change by construction, so it complements the level rules instead of replacing
> them. Nothing in the protocol changed: same signal envelope, same signature
> check, no new policy flag. Every number here is reproducible with one command.

## 1. Коротко

Оракул Axis теперь умеет отвечать на второй вопрос о пруфе — не только «кто это
прислал и не подменены ли байты», но и «согласовано ли это с тем, что слышит
парк». Ответ приходит не как мнение модели, а как число с объявленным заранее
критерием и с проверяемым эталоном: те же одиннадцать функций на Julia и на
Python дают одинаковый результат **до последнего бита**.

На объявленном парке из 8 производителей и 168 часов чтение поймало три из
четырёх изменений — включая подмену метки времени на два часа, которую не
видит ни подпись, ни правило уровня — и не тронуло ни одного исправного
производителя. Четвёртое изменение (уровень ×1.6) оно не видит **по
построению** и не пытается: это работа правил уровня.

## 2. Что сделано (факты и числа)

| | |
|---|---|
| новый код | `ENRG-AI/agent/physics/` — 8 модулей, ~1 500 строк |
| перенесено функций | 11 из `entrain/julia/kuramoto/basic.jl` |
| точность порта | расхождение с Julia 1.10.12 — **0.0** на всех 11 функциях и на 3 шагах полного закона |
| тесты | **64** новых; всего в ENRG-AI — **227**, все зелёные |
| изменений в L0 (протокол) | 0 |
| изменений в L1 (правила) | 0 |
| изменений в L2 (прошивка ESP32) | 0 |
| новых флагов политики | 0 (используется существующий opt-in `enforce_ai_anomaly`) |
| новый формат на проводе | 0 (`SignalBundle`, `kind="coherence"`) |
| лицензия | Apache-2.0 |

Эталон не «примерно такой же»: `tests/fixtures/entrain_reference.json`
сгенерирован самим Julia, рядом лежит `tests/fixtures/entrain_reference.jl`,
который воспроизводит его байт в байт. Любой сторонний аудитор может
перегенерировать эталон и сравнить.

## 3. Почему это не «ещё один детектор аномалий»

Обычные правила читают **уровень**: сколько энергии за час, сколько за сутки,
насколько это отличается от медианы истории. Такое чтение слепо к тому, *когда*
энергия пришла, если сумма сошлась.

Физика читает **время**: фазу суточного оборота, собственную частоту
производителя и записанную связь между производителями (память о том, кто с кем
совпадал). Множитель `×k` не двигает фазу — поэтому уровень невидим физике
по построению. И наоборот: сдвиг на два часа не меняет ни сумму за сутки, ни
подпись — поэтому он невидим уровню и криптографии.

| вопрос | кто отвечает |
|---|---|
| это то устройство и те ли байты? | подпись, nonce, проверка (L0–L2) |
| сколько пришло и не выбивается ли из истории? | правила уровня (L1, Axis-core) |
| **когда это пришло и согласовано ли с парком?** | **физика (L3, `agent/physics`)** |

Три вопроса — три разных ответа. Ни один не выводится из другого, и ни один не
отменяет остальные.

## 4. Результат пилота

Модельный парк: 8 производителей, 168 часов, 3 % шума, четыре изменения
объявлены **до** прогона (`python -m agent.physics.benchmark`, сид 7; числа
устойчивы на сидах 7 / 11 / 23 / 42).

| изменение | физика (coherence) | правила уровня (MAD) |
|---|---|---|
| отключение на сутки | **видит** (score 1.000) | видит, но с ложными |
| сдвиг пика на 4 ч | **видит** (phase + memory, 1.000) | видит, но с ложными |
| метка времени +2 ч | **видит** (phase, 0.634) | видит, но с ложными |
| уровень ×1.6 | не видит — по построению (0.179) | не видит: ниже порога правила |
| четыре исправных производителя | **молчит** (0.19–0.25) | почасовое правило кричит на всех четырёх |

| детектор | поймано | точность | полнота | ложных |
|---|---|---|---|---|
| coherence (физика) | 3 из 4 | **1.00** | 0.75 | **0** |
| spike MAD по часам | 4 из 4 | 0.50 | 1.00 | 4 |
| spike MAD по суткам | 0 из 4 | n/a | 0.00 | 0 |
| trend MAD (живой сигнал) | 4 из 4 | 0.57 | 1.00 | 3 |

Что здесь важно: на исправном парке физика даёт R = 0.989 и максимум 0.10 по
всем устройствам — то есть «тишина» это тоже число, а не отсутствие ответа.
А объединение детекторов честнее описывать так: физика + почасовое правило —
4 из 4 при четырёх ложных; физика + суточное правило — 3 из 4 при нуле ложных.
Идеального детектора из пары не получается, и мы этого не обещаем.

## 5. Чем это отличает Axis

**Рамка честности.** Утверждение «мы первые в DePIN, кто ловит фазовые сдвиги»
нельзя проверить из этого репозитория: мы не проводили обзор рынка и не будем
выдавать отсутствие знаний за факт. Что можно проверить — следующее:

1. Axis публикует измерение **согласованности парка** как первоклассный сигнал
   оракула (`kind="coherence"`), а не как внутреннюю эвристику.
2. Критерий объявлен **до** прогона и лежит в тестах вместе с ложными
   срабатываниями — включая неудобные для нас (правило уровня действительно
   ловит уровень, а мы его не видим).
3. Эталон реализации открыт: Julia и Python совпадают до последнего бита, и
   это можно перепроверить независимо.
4. Цена для доверия нулевая: интеграция не изменила ни байта протокола, ни
   одного флага политики.

Формулировка, которую мы готовы защищать: **единственный известный нам
DePIN-оракул, который публикует измерение фазовой согласованности вместе с
фальсифицируемым критерием, открытым эталоном и нулевым изменением протокола.**
Слово «известный нам» — часть утверждения, а не оговорка.

**Почему это ценно на практике.** Два класса проблем, которые раньше не
ловились вообще:

- **Спор о времени.** Энергия отнесена не к тому часу — тарифная зона, пик,
  расчётный период. Подпись валидна, сумма верна, история не выбивается; вопрос
  «когда» раньше не задавался.
- **Правдоподобная реконструкция.** Устройство присылает день, который
  выглядит нормально сам по себе, но не совпадает с тем, что слышал парк (пик
  сдвинут, тишина в середине, связь потеряна). Суммы сходятся — фаза нет.

И это не требует нового датчика: чтение использует те же пруфы, которые оракул
уже собирает.

## 6. Что это стоило протоколу — ничего

| уровень | что это | изменилось |
|---|---|---|
| L0 | Axis-protocol: подпись, nonce, минт | нет |
| L1 | Axis-core: правила проверки, политика | нет |
| L2 | прошивка ESP32 | нет |
| L3 | ENRG-AI: сигналы и наблюдения | + `agent/physics`, `kind="coherence"` |

Проверяемые следствия:

```python
from agent.signals import sign_bundle, verify_bundle_signature
# тот же конверт, что и раньше: подпись и проверка не менялись
verify_bundle_signature(payload["public_key"], payload)   # True
# подмена любого поля внутри конверта
verify_bundle_signature(tampered["public_key"], tampered) # False
```

`CoherenceSignal` подходит к существующему opt-in гейту
`PolicyEngine.evaluate_ai_anomaly` без нового кода причины: при выключенном
флаге — `allowed=True`, при включённом — `allowed=False`,
`reason="ai_anomaly_flagged"`, а `ai_signals` перечисляет сработавшие чтения
(например, `["phase", "memory"]` у производителя со сдвинутым пиком).

## 7. Пределы, которые мы называем сами

1. **Сговор невидим.** Согласованность — это «один из N выпал», а не истина.
   Если все производители согласованно врут, R высок и никто не сработает.
   Это свойство метода, а не недосмотр, и оно записано в границе.
2. **Живых данных пока нет.** Всё измерено на модели; на реальном парке
   (разная погода по площадке, тени, обледенение) числа сдвинутся. Нужен пилот
   ≥ 7 дней и ≥ 2 устройств.
3. **Чтение суточное.** Фаза отвечает по последним 24 часам; шаг читается
   наполовину через 12 часов. Для онлайна нужен причинный фильтр — отдельная
   работа.
4. **Это не измерение физики, а чтение отчётов.** Чтобы стало измерением,
   нужен датчик (например, освещённости) — отдельное решение.
5. **Метрика ничего не разрешает.** Она не влияет на минт, начисление или
   расчёт ERS. Только предлагает внимание оператора.

## 8. Как проверить за десять минут

```bash
cd ENRG-AI
python -m agent.physics.benchmark                 # таблица «физика против MAD»
python -m agent.physics --scenario mixed --output coherence.json
python -m pytest tests/test_physics_oscillator.py tests/test_physics_benchmark.py -q
```

Ожидаемое (сид по умолчанию 7):

```
coherence       caught 3/4  precision 1.00  recall 0.75  false alarms 0
spike_mad       caught 4/4  precision 0.50  recall 1.00  false alarms 4
spike_mad_daily caught 0/4  precision n/a   recall 0.00  false alarms 0
trend_mad       caught 4/4  precision 0.57  recall 1.00  false alarms 3
```

Если эти числа не воспроизводятся — это ошибка, а не «другая точка зрения»:
критерий объявлен, данные детерминированы сидом.
